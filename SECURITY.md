# Security
Found a vulnerability (consensus bug, key handling, remote crash)? Please do **not** open a public issue first. Use GitHub's "Report a vulnerability" (Security tab) so a fix can ship before it is public.
- Never share your 24-word recovery phrase. No maintainer will ever ask for it.
- This software has had no independent audit. It is experimental.
- Official downloads are only from this repository's Releases. Check `SHA256SUMS.txt`.
